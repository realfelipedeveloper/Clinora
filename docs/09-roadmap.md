# Roadmap

As specs aprovadas para as Releases 1–10 estão em [specs/README.md](../specs/README.md).
A SPEC-001 permanece ativa até concluir a fundação; as demais seguem a
sequência aprovada após CI e merge do PR #82.

Release 0: fundação.
Release 1: identidade, tenants e autorização.
Release 2: pacientes, profissionais, especialidades, serviços, salas, equipamentos e convênios.
Release 3: disponibilidade, exceções, bloqueios, recorrência e timezone.
Release 4: hold, confirmação, cancelamento, reagendamento, máquina de estados e concorrência.
Release 5: lista de espera, check-in, encaixes e no-show.
Release 6: Payment API fake.
Release 7: Notification API.
Release 8: SaaS, planos, feature flags e billing.
Release 9: integrações fake, calendários, teleconsulta e FHIR preparado.
Release 10: hardening, LGPD, branding e preparação comercial.

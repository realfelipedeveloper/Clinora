# Engineering Loop

1. LOAD CONTEXT
2. VALIDATE ACTIVE SPEC
3. IMPACT ANALYSIS
4. DOMAIN/CONCURRENCY/TIMEZONE REVIEW
5. THREAT AND PRIVACY MODEL
6. WRITE OR UPDATE TESTS
7. IMPLEMENT MINIMAL CHANGE
8. LOCAL VALIDATION
9. REGRESSION AND CONTRACTS
10. SECURITY CHECKS
11. REVIEW DIFF
12. UPDATE DOCUMENTATION AND MEMORY
13. COMPLETION REPORT

Falha em gate retorna ao ponto impactado. É proibido remover testes apenas para liberar o pipeline.
